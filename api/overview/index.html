API Overview¶

Welcome to the FollowMyLead API documentation. Our REST API provides full programmatic access to manage leads, workflows, automations, and integrations.

Base URL¶

https://api.mycompany.com/v1

API Versions¶

Version Status Deprecated
v1 ✅ Current -
v0 ⚠️ Legacy 2024-12-31

Key Features¶

  • RESTful — Standard HTTP methods
  • JSON — Request and response format
  • Authentication — API Keys and OAuth 2.0
  • Rate Limiting — 1000 requests per minute
  • Webhooks — Real-time event notifications
  • Pagination — Limit/offset support
  • Batch Operations — Process multiple records

Quick Start¶

1. Get Your API Key¶

Visit your https://dashboard.mycompany.com → Settings → API Keys

2. Make Your First Request¶

curl -X GET https://api.mycompany.com/v1/leads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

3. Parse the Response¶

{
  "data": [
    {
      "id": "lead_123",
      "email": "john@example.com",
      "first_name": "John",
      "last_name": "Doe",
      "company": "Acme Corp",
      "created_at": "2024-05-02T10:30:00Z"
    }
  ],
  "meta": {
    "total": 1234,
    "limit": 20,
    "offset": 0
  }
}

Request Format¶

Headers¶

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
X-Request-ID: unique_request_id (optional)

Query Parameters¶

Parameter Type Description
limit integer Results per page (default: 20, max: 100)
offset integer Pagination offset (default: 0)
sort string Sort field (e.g., created_at:desc)
filter string Filter expression

Request Body¶

{
  "email": "john@example.com",
  "first_name": "John",
  "last_name": "Doe",
  "company": "Acme Corp",
  "metadata": {
    "source": "web_form",
    "campaign": "summer_2024"
  }
}

Response Format¶

Success Response (200 OK)¶

{
  "data": { /* Resource object */ },
  "meta": {
    "timestamp": "2024-05-02T10:30:00Z",
    "request_id": "req_abc123"
  }
}

Error Response (4xx/5xx)¶

{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Invalid email address",
    "details": {
      "field": "email",
      "reason": "format_invalid"
    }
  }
}

HTTP Status Codes¶

Code Meaning Example
200 OK Request succeeded
201 Created Resource created
204 No Content Success, no response
400 Bad Request Invalid parameters
401 Unauthorized Missing/invalid API key
403 Forbidden Insufficient permissions
404 Not Found Resource not found
429 Rate Limited Too many requests
500 Server Error Internal error

Rate Limiting¶

API requests are rate-limited to 1000 per minute per API key.

Rate Limit Headers¶

X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 999
X-RateLimit-Reset: 1714744200

Handling Rate Limits¶

import time

def make_request_with_retry(url, max_retries=3):
    for attempt in range(max_retries):
        response = requests.get(url, headers=headers)

        if response.status_code == 429:
            reset_time = int(response.headers['X-RateLimit-Reset'])
            sleep_duration = reset_time - time.time()
            time.sleep(sleep_duration)
            continue

        return response

    raise Exception("Max retries exceeded")

Pagination¶

Use limit and offset for paginating results:

# First page
https://api.mycompany.com/v1/leads?limit=20&offset=0

# Next page
https://api.mycompany.com/v1/leads?limit=20&offset=20

# Third page
https://api.mycompany.com/v1/leads?limit=20&offset=40

Filtering¶

Filter results using query parameters:

# Filter by company
https://api.mycompany.com/v1/leads?filter[company]=Acme%20Corp

# Filter by date range
https://api.mycompany.com/v1/leads?filter[created_at][$gte]=2024-05-01&filter[created_at][$lte]=2024-05-31

# Filter by status
https://api.mycompany.com/v1/leads?filter[status]=active

Examples¶

Create a Lead¶

curl -X POST https://api.mycompany.com/v1/leads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john@example.com",
    "first_name": "John",
    "last_name": "Doe",
    "company": "Acme Corp"
  }'

List Leads¶

curl -X GET "https://api.mycompany.com/v1/leads?limit=20&sort=created_at:desc" \
  -H "Authorization: Bearer YOUR_API_KEY"

Update a Lead¶

curl -X PATCH https://api.mycompany.com/v1/leads/lead_123 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "qualified"
  }'

Delete a Lead¶

curl -X DELETE https://api.mycompany.com/v1/leads/lead_123 \
  -H "Authorization: Bearer YOUR_API_KEY"
