API Endpoints¶

Complete reference for all FollowMyLead API endpoints.

Leads¶

List Leads¶

Retrieve all leads with optional filtering.

GET https://api.mycompany.com/v1/leads

Query Parameters:

Parameter Type Description
limit integer Results per page (default: 20, max: 100)
offset integer Pagination offset (default: 0)
sort string Sort field with direction (e.g., created_at:desc)
filter object Filter conditions

Example:

curl -X GET "https://api.mycompany.com/v1/leads?limit=20&offset=0&sort=created_at:desc" \
  -H "Authorization: Bearer YOUR_API_KEY"

Response:

{
  "data": [
    {
      "id": "lead_123",
      "email": "john@example.com",
      "first_name": "John",
      "last_name": "Doe",
      "company": "Acme Corp",
      "status": "active",
      "lead_score": 85,
      "created_at": "2024-05-02T10:30:00Z",
      "updated_at": "2024-05-02T10:30:00Z"
    }
  ],
  "meta": {
    "total": 1234,
    "limit": 20,
    "offset": 0
  }
}

Get Lead by ID¶

Retrieve a specific lead.

GET https://api.mycompany.com/v1/leads/:lead_id

Example:

curl -X GET https://api.mycompany.com/v1/leads/lead_123 \
  -H "Authorization: Bearer YOUR_API_KEY"

Create a Lead¶

Create a new lead.

POST https://api.mycompany.com/v1/leads

Request Body:

{
  "email": "jane@example.com",
  "first_name": "Jane",
  "last_name": "Smith",
  "company": "Tech Innovations Inc",
  "phone": "+1987654321",
  "website": "https://techinnovations.com",
  "industry": "SaaS",
  "company_size": "50-100",
  "source": "web_form",
  "tags": ["inbound", "website"],
  "custom_fields": {
    "budget": "$50,000",
    "use_case": "CRM Integration"
  }
}

Example:

curl -X POST https://api.mycompany.com/v1/leads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "jane@example.com",
    "first_name": "Jane",
    "last_name": "Smith",
    "company": "Tech Innovations Inc"
  }'

Response (201 Created):

{
  "data": {
    "id": "lead_456",
    "email": "jane@example.com",
    "first_name": "Jane",
    "last_name": "Smith",
    "company": "Tech Innovations Inc",
    "status": "active",
    "lead_score": 0,
    "created_at": "2024-05-02T11:00:00Z",
    "updated_at": "2024-05-02T11:00:00Z"
  }
}

Update a Lead¶

Update an existing lead.

PATCH https://api.mycompany.com/v1/leads/:lead_id

Request Body:

{
  "status": "qualified",
  "lead_score": 95,
  "tags": ["hot_prospect"],
  "custom_fields": {
    "last_contact": "2024-05-02"
  }
}

Example:

curl -X PATCH https://api.mycompany.com/v1/leads/lead_123 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "qualified",
    "lead_score": 95
  }'

Response (200 OK):

{
  "data": {
    "id": "lead_123",
    "email": "john@example.com",
    "first_name": "John",
    "last_name": "Doe",
    "company": "Acme Corp",
    "status": "qualified",
    "lead_score": 95,
    "updated_at": "2024-05-02T11:15:00Z"
  }
}

Delete a Lead¶

Delete a lead permanently.

DELETE https://api.mycompany.com/v1/leads/:lead_id

Example:

curl -X DELETE https://api.mycompany.com/v1/leads/lead_123 \
  -H "Authorization: Bearer YOUR_API_KEY"

Response (204 No Content):

(empty response)

{

  "active": true
}

Error Codes¶

Code Meaning Solution
INVALID_REQUEST Bad request format Check request body and parameters
UNAUTHORIZED Invalid API key Verify API key in Authorization header
FORBIDDEN Insufficient permissions Check API key scopes
NOT_FOUND Resource not found Verify resource ID
CONFLICT Resource already exists Check for duplicates
RATE_LIMITED Too many requests Implement exponential backoff
INTERNAL_ERROR Server error Retry or contact support
