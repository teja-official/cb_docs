Integrations¶

Connect FollowMyLead with your favorite tools and platforms. Our extensive integration library enables seamless data flow across your entire tech stack.

Popular Integrations¶

CRM Systems¶

Salesforce¶

Integration: Salesforce
Base URL: https://salesforce.com
Authentication: OAuth 2.0
Sync Direction: Bidirectional

Features:
├─ Auto-create leads in Salesforce
├─ Sync custom fields
├─ Add to campaigns automatically
├─ Track email opens in Salesforce
└─ Log all activities

Setup: 1. Go to Integrations → Salesforce 2. Click Connect 3. Authorize with Salesforce credentials 4. Map custom fields 5. Choose sync frequency

Building Custom Integrations¶

Webhook Support¶

Receive real-time updates via webhooks:

POST https://api.mycompany.com/v1/webhooks/events

Headers:
  Content-Type: application/json
  X-Signature: sha256_signature

Body:
{
  "event": "lead.created",
  "timestamp": "2024-05-02T10:30:00Z",
  "data": {
    "lead_id": "abc123",
    "email": "john@example.com",
    "name": "John Doe",
    "company": "Acme Corp"
  }
}

REST API Integration¶

import requests

BASE_URL = "https://api.mycompany.com/v1"
API_KEY = "your_api_key"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# Create a lead
response = requests.post(
    f"{BASE_URL}/leads",
    headers=headers,
    json={
        "email": "john@example.com",
        "first_name": "John",
        "last_name": "Doe",
        "company": "Acme Corp"
    }
)

print(response.json())

Webhook Signature Verification¶

Verify webhook authenticity:

import hmac
import hashlib

WEBHOOK_SECRET = "your_webhook_secret"

def verify_signature(payload, signature):
    expected = hmac.new(
        WEBHOOK_SECRET.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature)

# In your webhook handler
if verify_signature(payload, x_signature):
    # Process webhook
    pass

Integration Workflows¶

Flow 1: Salesforce → FollowMyLead → Email¶

1. Lead created in Salesforce
   ↓
2. Webhook triggers FollowMyLead
   ↓
3. Lead enrichment workflow
   ↓
4. Auto-send welcome email
   ↓
5. Track opens in FollowMyLead
   ↓
6. Sync engagement back to Salesforce

Flow 2: Web Form → HubSpot → WhatsApp¶

1. User submits web form
   ↓
2. Form service creates contact in HubSpot
   ↓
3. HubSpot triggers FollowMyLead workflow
   ↓
4. Send WhatsApp message
   ↓
5. Track responses
   ↓
6. Update HubSpot contact properties

Authentication Methods¶

Bearer Token¶

curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.mycompany.com/v1/leads

API Key Header¶

curl -H "X-API-Key: YOUR_API_KEY" \
  https://api.mycompany.com/v1/leads

OAuth 2.0¶

# 1. Redirect to authorization endpoint
https://api.mycompany.com/v1/oauth/authorize
?client_id=YOUR_CLIENT_ID
&redirect_uri=https://yourapp.com/callback
&scope=read:leads,write:leads

# 2. Exchange code for token
curl -X POST https://api.mycompany.com/v1/oauth/token \
  -d grant_type=authorization_code \
  -d code=AUTHORIZATION_CODE \
  -d client_id=YOUR_CLIENT_ID \
  -d client_secret=YOUR_CLIENT_SECRET

  • Data mismatch — Check field mapping and data types
  • Rate limiting — Implement exponential backoff
