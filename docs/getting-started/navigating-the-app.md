# Finding your way around

## The top bar

From left to right:

| Element | What it does |
|---|---|
| **Logo & workspace switcher** | Shows the current workspace. Click it to switch to another workspace you belong to. |
| **Search pages…** | Jump to any page. Press ++ctrl+k++ (Windows/Linux) or ++cmd+k++ (Mac). Pages that need a plan show a lock. |
| **App / Account** | Switches the sidebar between the app pages and your personal account pages. |
| **Live status dot** | Green when the real-time connection is up. If it's grey, updates may be delayed — reload the page. |
| **Take a Tour** | Starts the guided tour (setup steps for admins, the conversation queue for agents). |
| **Theme toggle** | Light or dark mode. Set a permanent choice (including *System*) in [Account settings](../account/account-settings.md#appearance). |
| **Notification bell** | In-app notifications: handoffs, new messages, knowledge base results, billing, team and lead-source events. See [Notifications](../account/notifications.md). |
| **Avatar menu** | Profile, account settings, **Help & Support**, and log out. |

## The app sidebar

What you see depends on your [role and permissions](../workspace/team-and-roles.md).

| Group | Page | What it's for |
|---|---|---|
| — | :lucide-chart-pie: **Dashboard** / :lucide-headset: **My Dashboard** | Workspace metrics (admins) or your own queue and stats (agents). [Dashboards](../engage/dashboards.md) |
| **Engage** | :lucide-scan-eye: **Nurture Campaigns** | Create and manage campaigns. [Nurture campaigns](../nurture-campaigns/index.md) |
| | :lucide-bot-message-square: **Conversations** | The live inbox. [Conversations](../engage/conversations.md) |
| | :lucide-book-user: **Leads** | Every lead and its status. [Leads](../engage/leads.md) |
| **Setup** | :lucide-brain: **AI Models** | AI providers and API keys. [AI models](../setup/ai-models.md) |
| | :lucide-radio: **Channels** | WhatsApp, Telegram, Email, SMS. [Channels](../setup/channels/index.md) |
| | :lucide-users: **Human Agents** | Who receives handoffs. [Human agents](../setup/human-agents.md) |
| | :lucide-puzzle: **Lead Sources** | Meta Ads, Google Ads, Sheets, uploads. [Lead sources](../setup/lead-sources/index.md) |
| **Workspace** | :lucide-blocks: **Team & Workspace** | Members, invitations, roles. [Team & roles](../workspace/team-and-roles.md) |
| | :lucide-settings: **Settings** | Workspace messaging rules. [Workspace settings](../workspace/workspace-settings.md) |

You can collapse the sidebar to get more room; to start with it collapsed every time, change it in [Account settings](../account/account-settings.md#appearance).

## The account sidebar

Click **Account** in the top bar (or your avatar → **Profile**):

- :lucide-user-pen: **Profile** — name, phone, email. [Profile](../account/profile.md)
- :lucide-settings: **Account Settings** — emails, notifications, appearance, region, security. [Account settings](../account/account-settings.md)
- :lucide-life-buoy: **Help & Support** — support tickets. [Help & support](../account/support.md)
- **Billing:** :lucide-layout-dashboard: **Subscription**, :lucide-chart-column: **Plan Usage**, :lucide-history: **Payment History**, :lucide-gift: **Referrals**. [Billing](../account/billing.md)

## In-app help

Look for the :lucide-circle-help: help button on setup screens (Channels, AI Models, Lead Sources, the campaign wizard, Team & Workspace). It opens the same step-by-step guides you'll find in this Help Center. Next to credential fields, **Where do I find this?** opens the guide for that provider.
